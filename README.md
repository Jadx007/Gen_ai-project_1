# Gen_ai-project_1

Jad Multilingual Text-to-Image Generator is an AI-powered application that allows users to generate images by entering text prompts in multiple languages. It uses Artificial Intelligence (AI), Deep Learning, and pretrained text-to-image models to transform textual descriptions into visual images.

Users can describe an image in English, Tamil, Hindi, French, Spanish, and other supported languages. The application processes the prompt and generates a corresponding image.

For example:

🇬🇧 English: A cute Pikachu in a colorful garden.

🇮🇳 Tamil: வண்ணமயமான தோட்டத்தில் ஒரு அழகான பிகாசு.

🇮🇳 Hindi: एक रंगीन बगीचे में एक प्यारा पिकाचू।

🇫🇷 French: Un joli Pikachu dans un jardin coloré.
